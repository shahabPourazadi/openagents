# Research skill

## Clarify

- One sentence research question
- Audience and depth (skim vs deep dive)
- Any must-include / must-avoid sources

## Gather

1. Search broadly, then scrape the best 3–7 sources.
2. Capture title, URL, date (if available), and one-line relevance.
3. Quote sparingly; paraphrase with attribution.

## Structure the document

Use `suggest_edit` to keep these sections healthy:

- **Question** — locked scope
- **Findings** — bullets grouped by theme, each with a source marker
- **Sources** — numbered list of real URLs
- **Next steps** — open questions or follow-up searches

## Honesty rules

- Never invent citations.
- Mark uncertainty explicitly (“unverified”, “single-source”).
- If tools fail, ask the user for links or paste.
